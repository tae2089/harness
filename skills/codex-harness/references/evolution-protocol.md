# Harness Maintenance

Audit only the requested scope: generated role definitions, skill references, project instructions, shared tracker contract, and relevant work records.

1. Compare generated model and effort assignments with the selected policy.
2. Check generated references exist and the issue/document publication dependencies are available when needed.
3. Inspect actual deliverables and checks before interpreting progress reports.
4. Report drift and its consequence; apply requested changes without replacing unrelated instructions.
5. Validate the affected generation and execution scenarios.

Do not create a local execution database to perform an audit. Do not reset, delete, or rewrite historical work merely because its format is obsolete. Follow expansion-matrix.md when migrating an existing project.
