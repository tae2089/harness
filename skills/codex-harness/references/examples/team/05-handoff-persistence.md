# Incident Handoff and Resume

1. An Analyst investigates logs, then recommends a specialist or Operator based on evidence.

2. The main Orchestrator passes relevant observations and remaining questions to the selected role. Operational actions respect existing approval requirements.

3. Before interruption, record verified findings, blockers, and next action on the issue. On resume, read that record and inspect current system evidence. Without an issue, use the conversation and an optional handoff note.

Use the shared project policy and runtime procedure. Native Codex subagents return results to the main Orchestrator. Scratch notes are optional; actual artifacts and verification evidence determine completion.
