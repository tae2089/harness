# Hierarchical Full-Stack Work

1. An Architect decomposes the feature into frontend/backend responsibilities and interface contracts.

2. The main Orchestrator spawns the corresponding workers itself. Team leads return plans and review findings, not nested agent calls.

3. Verify integration against the shared interface and tests. Record progress on the work unit, not per internal role.

Use the shared project policy and runtime procedure. Native Codex subagents return results to the main Orchestrator. Scratch notes are optional; actual artifacts and verification evidence determine completion.
