# Parallel Competitor Research

1. The main Orchestrator assigns bounded source research to independent Researchers, then asks an Analyst to synthesize findings.

2. Researchers return source references, findings, uncertainties, and proposed follow-ups directly. The Analyst reconciles contradictions and produces the agreed report.

3. Verify cited evidence and publish the report via the selected document contract. Record one work unit's progress, not an issue per researcher.

Use the shared project policy and runtime procedure. Native Codex subagents return results to the main Orchestrator. Scratch notes are optional; actual artifacts and verification evidence determine completion.
