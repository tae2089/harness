# Architecture Design

1. An Architect reads the linked requirements, code boundaries, and constraints.

2. Compare concrete alternatives and record the selected design through the shared document contract. Obtain user decisions where tradeoffs materially change the scope.

3. Review the design against requirements and current code. Resume from that document and current artifacts, not an internal stage pointer.

Use the shared project policy and runtime procedure. Native Codex subagents return results to the main Orchestrator. Scratch notes are optional; actual artifacts and verification evidence determine completion.
