# Independent Work Within One Deliverable

1. Split an authorized deliverable into independent bounded responsibilities.

2. The main Orchestrator assigns clear ownership, waits for results, and resolves overlapping assumptions before integration.

3. One work unit retains one issue; internal worker calls and retries are recorded only when they change meaningful progress.

Use the shared project policy and runtime procedure. Native Codex subagents return results to the main Orchestrator. Scratch notes are optional; actual artifacts and verification evidence determine completion.
