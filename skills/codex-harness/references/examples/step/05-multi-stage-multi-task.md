# Dependent Design, Implementation, and Verification

1. Express dependencies and completion criteria in the selected spec or issue.

2. Verify design inputs before implementation, then run independent review and appropriate integration checks. Parallelize independent portions only.

3. Publish evidence and remaining work at meaningful milestones. Keep issue closure separate from implementation completion.

Use the shared project policy and runtime procedure. Native Codex subagents return results to the main Orchestrator. Scratch notes are optional; actual artifacts and verification evidence determine completion.
