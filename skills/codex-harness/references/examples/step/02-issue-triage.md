# Issue Triage

1. Read only the user-selected issue or authorized issue set.

2. An Analyst categorizes evidence and proposes next actions. The main Orchestrator updates comments or applicable nonterminal status within scope.

3. Do not close issues automatically or create an issue per triage step. Preserve human-authored requirements.

Use the shared project policy and runtime procedure. Native Codex subagents return results to the main Orchestrator. Scratch notes are optional; actual artifacts and verification evidence determine completion.
