# SSO Harness Example

1. Generate Architect, Developer, Reviewer, and QA agent definitions from the worker template and explicit model policy.

2. Generate an sso-orchestrator skill with project-policy.md, orchestrator-procedures.md, and schemas/models.md. Merge its entry pointer, tracker policy, and user-selected explanation profile into AGENTS.md.

3. For execution, select existing/new/no issue, read authentication requirements, inspect code, implement bounded changes, review, and verify. Publish the spec through to-spec and work tickets through to-issues when requested. Resume by checking work records and code/tests. Never close the issue without user instruction.

Use the shared project policy and runtime procedure. Native Codex subagents return results to the main Orchestrator. Scratch notes are optional; actual artifacts and verification evidence determine completion.
